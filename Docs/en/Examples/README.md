# Code Examples

This directory contains runnable code examples for NetworkHealth.

## Available Examples

### NetworkHealthExamples.swift

Complete Swift file with 17+ real-world examples covering:

- **Stream Mode Examples** (Examples 1-3)
  - Basic network monitoring
  - Stream with speed tests
  - Background monitoring service

- **Snapshot Mode Examples** (Examples 4-6)
  - Quick quality check
  - Detailed snapshot with speed test
  - Pre-flight check for API calls

- **Observable Mode Examples** (Examples 7-9)
  - SwiftUI network status view
  - SwiftUI with speed testing
  - Conditional video player

- **Health Check Examples** (Examples 10-13)
  - Video streaming check
  - Custom requirements check
  - Multiple operation checks
  - Adaptive content loading

- **Real-World Use Cases** (Examples 14-17)
  - Download manager with priority handling
  - API client with adaptive timeout
  - Image loading service with quality adaptation
  - Video streaming manager with bitrate adaptation

## How to Use

You can copy any example function from `NetworkHealthExamples.swift` and integrate it into your project. Each example is self-contained and demonstrates a specific use case.

### Quick Integration

1. Open `NetworkHealthExamples.swift`
2. Find the example that matches your use case
3. Copy the relevant code
4. Adapt it to your needs

### Running Examples

The examples are designed to be copied into your project. Some examples require:
- `NetworkProvider` from SpeedTestCore (for speed testing examples)
- SwiftUI views to be embedded in your app
