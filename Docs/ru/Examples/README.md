# Примеры кода

Эта директория содержит исполняемые примеры кода для NetworkHealth.

## Доступные примеры

### NetworkHealthExamples.swift

Полный Swift файл с 17+ примерами из реальных проектов:

- **Примеры Stream Mode** (Примеры 1-3)
  - Базовый мониторинг сети
  - Stream с тестами скорости
  - Сервис фонового мониторинга

- **Примеры Snapshot Mode** (Примеры 4-6)
  - Быстрая проверка качества
  - Детальный snapshot с тестом скорости
  - Предварительная проверка для API вызовов

- **Примеры Observable Mode** (Примеры 7-9)
  - SwiftUI вью статуса сети
  - SwiftUI с тестированием скорости
  - Условный видео плеер

- **Примеры Health Check** (Примеры 10-13)
  - Проверка для видео стриминга
  - Проверка кастомных требований
  - Множественные проверки операций
  - Адаптивная загрузка контента

- **Примеры из реальных проектов** (Примеры 14-17)
  - Менеджер загрузок с приоритетами
  - API клиент с адаптивным таймаутом
  - Сервис загрузки изображений с адаптацией качества
  - Менеджер видео стриминга с адаптацией битрейта

## Как использовать

Вы можете скопировать любую функцию из `NetworkHealthExamples.swift` и интегрировать её в свой проект. Каждый пример самодостаточен и демонстрирует конкретный случай использования.

### Быстрая интеграция

1. Откройте `NetworkHealthExamples.swift`
2. Найдите пример, подходящий для вашего случая
3. Скопируйте соответствующий код
4. Адаптируйте под свои нужды

### Запуск примеров

Примеры разработаны для копирования в ваш проект. Некоторые примеры требуют:
- `NetworkProvider` из SpeedTestCore (для примеров с тестированием скорости)
- SwiftUI views должны быть встроены в ваше приложение
